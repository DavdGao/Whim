# Source and coding plugin icons

Brand marks are centered without an extra tinted tile. SVGs keep their original aspect ratio; raster images with backgrounds are clipped to a circle. Retrieved on November 17, 2026.

| Plugin               | Asset and provenance                                                                                                                                                                                                                                                                                               |
| -------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Reddit               | SVG from the [official brand page](https://redditinc.com/brand): [asset](https://redditinc.com/hubfs/Reddit%20Inc/Content/Brand%20Page/Reddit_Lockup_Logo.svg). The viewport isolates the original Snoo symbol from the wordmark. See the [trademark policy](https://redditinc.com/policies/trademark-use-policy). |
| arXiv                | Unmodified vector logo linked by the [official brand guide](https://info.arxiv.org/brand/index.html): [asset](https://static.arxiv.org/static/design-system/latest/logos/arxiv-logo.svg).                                                                                                                          |
| Xiaohongshu          | Transparent wordmark from [Simple Icons](https://github.com/simple-icons/simple-icons/blob/develop/icons/xiaohongshu.svg), distributed under CC0; filled with the brand red.                                                                                                                                       |
| OpenAI coding plugin | Transparent OpenAI mark from `@lobehub/icons-static-svg` 1.102.0 (`openai.svg`, MIT), with an explicit dark fill for image rendering.                                                                                                                                                                              |
| Claude Code          | Transparent Claude mark from `@lobehub/icons-static-svg` 1.102.0 (`claude-color.svg`, MIT).                                                                                                                                                                                                                        |

Trademarks remain their owners' property. The official Reddit and arXiv assets are not claimed to have an open-source license. Existing Bailian/Qwen, Tavily and TypeSafe marks retain the sources and licenses documented in their provider pages. Assets use Core's bounded plugin-icon pipeline.
