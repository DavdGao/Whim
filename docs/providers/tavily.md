# Tavily

Facts used by `@whimkit/plugin-tavily`, which implements the local `WebSearch` tool with `POST https://api.tavily.com/search` (`search_depth: basic`) and the user's Tavily API key.

## Icons

`icons/tavily.svg` is the colored Tavily mark from `@lobehub/icons-static-svg` 1.102.0 (MIT). The mark remains a trademark of its owner and identifies the search provider only.
